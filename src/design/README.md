# Design — UI-prototype

`house-passport-ui.jsx` er en **klikbar designprototype** (React, ét fil) der
viser designsystemet fra `docs/05-Design.md` bragt til live: onboarding,
dashboard og dokumentcenter med data formet som API'ets svar.

Det er en *prototype*, ikke produktions-frontenden. Produktionsversionen er en
Next.js-app (jf. stacken i briefet), der wires mod `house-passport-api`-endpoints
bag rigtig auth. Prototypen bruges som visuel reference under den implementering.
